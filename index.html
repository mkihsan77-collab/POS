To use the same products and bills on multiple devices, connect a Supabase project and enable Row Level Security (RLS). Do not put a service-role secret in browser code.

  1. Create a project at supabase.com.
  2. Run the included supabase-schema.sql in SQL Editor.
  3. Enable authentication and add per-shop access policies before real use.
  4. Configure the public project URL and anon key in the deployed app.
  5. Test with two devices and separate user accounts before entering real sales.

This preview does not connect to Supabase or sync data. The included starter SQL is a schema foundation, not a complete secured multi-tenant production deployment.
